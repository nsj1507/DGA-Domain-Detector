# Risk badge

**Source evidence:** `artifacts/dga-domain-detector/src/pages/home.tsx`,
verdict header, system status pill, and history rows.

Badges are compact, uppercase, monospaced labels. Low-risk and active states
use lime-derived greens; malicious and error states use a muted red family.
Badges should clarify a nearby value, not replace the verdict heading.

**Design-system mapping:** use Badge variants with the semantic accent and
destructive tokens.
