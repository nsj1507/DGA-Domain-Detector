# System alert

**Source evidence:** `artifacts/dga-domain-detector/src/pages/home.tsx`,
model-unavailable and analysis-error states.

Attention messages are quiet, bordered callouts with a small leading icon,
short direct copy, and enough contrast to remain visible without dominating
the analysis surface. Use warning colors for availability and muted red for
failed analysis or malicious outcomes.

**Design-system mapping:** use Alert variants and semantic tokens.
